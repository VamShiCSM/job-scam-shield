# 🚀 Smart Job Scam Prevention System

An AI-powered web application that detects and prevents fake job postings using **Machine Learning** and **verified user reports**.

This system analyzes job descriptions or emails in real time and helps users identify potential scams quickly and safely.

---

## ✨ Features

- 🔍 Paste job description or email to analyze
- 🤖 ML-powered scam detection
- ⚡ Instant results
- 🔐 No login required for checking
- 📊 Scam awareness dashboard
- 🛡️ User reporting system
- 📱 Responsive modern UI

---

## 🛠️ Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (backend)
- Machine Learning API
